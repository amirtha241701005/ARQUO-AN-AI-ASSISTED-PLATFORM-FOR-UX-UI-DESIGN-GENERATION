# ARQUO
### An AI-Assisted Platform for UX/UI Design Generation

ARQUO is an AI-powered UI/UX design workspace that transforms natural-language design prompts into structured, multi-screen user interfaces.

The platform uses Qwen 3.5 through Ollama to support AI-driven design generation and UX workflows.

## Technology Stack

- Next.js
- React
- TypeScript
- Ollama
- Qwen 3.5

## Getting Started

### Prerequisites

- Node.js and npm
- Ollama installed and running
- The Qwen model used by the project downloaded in Ollama
